# 🎵 lkimlamdev – SoundCloud Downloader

Trang web tải nhạc và nghe thử SoundCloud miễn phí, nhanh chóng với giao diện hiện đại được thiết kế theo phong cách tối giản của **soundloadmate.net**.

---

## ✨ Tính năng nổi bật

- 🎧 **Nghe trước bài hát (Audio Preview)**: Tích hợp Custom Player với thanh tua seekbar, hiển thị thời gian, hiệu ứng sóng âm hoạt họa (Audio Waveform) và hỗ trợ cả luồng **HLS** lẫn **Progressive MP3**.
- ⚡ **Tải nhạc MP3 tốc độ cao**: Chuyển đổi và tải bài hát trực tiếp sang định dạng `.mp3` chất lượng gốc.
- 🎨 **Giao diện hiện đại**: Dark theme sang trọng kết hợp màu cam SoundCloud, hiệu ứng hạt particles tương tác.
- 📱 **Tương thích toàn diện**: Hoạt động mượt mà trên Desktop, Laptop, Máy tính bảng và Điện thoại di động.
- 🔒 **Bảo mật & Miễn phí**: Không cần đăng nhập, không lưu trữ dữ liệu cá nhân của người dùng.

---

## 🛠️ Công nghệ sử dụng

- **Backend**: Node.js, Express, Axios, CORS
- **Frontend**: HTML5, CSS3 (Modern Flexbox/Grid, Animations), JavaScript ES6+
- **Audio Streaming**: HLS.js & Native Audio API

---

## 🚀 Hướng dẫn cài đặt và khởi chạy

### Cách 1: Khởi động nhanh (Khuyên dùng)
Chỉ cần nhấp đúp chuột vào file **`start.bat`** trong thư mục dự án.

### Cách 2: Chạy qua dòng lệnh (Terminal / CMD)
```bash
# 1. Cài đặt các gói thư viện
npm install

# 2. Khởi động server
npm start
```

Mở trình duyệt web và truy cập: **`http://localhost:3000`**
